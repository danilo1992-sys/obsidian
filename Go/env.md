# env

para utilizar las varibales de entorno dentro de go hay que crear un archivo .env en la raiz del projecto, este archivo tendra todas las varibales de entorno que creamos nesesarias, la momento de publicar el codigo en un repositorio !!!No hay que publicar el archivo!!! si un .env.demo que sirve para indicarle al usuario que varibale de entorno tiene que usar

```.env
DB_NAME=prueba
DB_USER=root
DB_PASSWORD=root
DB_SERVER=localhost
DB_PORTS=3306

```
