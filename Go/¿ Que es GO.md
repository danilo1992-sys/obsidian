# ¿ Que es GO ?

es un lenguaje de programación concurrente estos significa que puede trabajar con  esquemas orientados a diagramas de flujo te permite implementar reglas de negocios ejemplo el modelo vista controlador 

la sintaxis esta inspirada en el leguaje de c 

tiene seguridad en memoria y recolección de basura, esto sucede por que go esta orientado a la performance para poder ser ejecutado en cualquier sistema operativo independientemente de sus recursos para lograr una mayor eficiencia.

go empezó su desarrollo en el año 2007 por parte de Google y lanzado al publico en el año 2009 , en la actualidad se encuentra disponible para Windows y sistemas operativos basados en Unix (Linux, Macos y FreeBSD ) 

  

## Características

- Fácil de aprender y excelente para equipos
- Es de código abierto
- Permite ejecutar varios procesos a la vez dependiendo la capacidad de la pc y una biblioteca que cumple con todas las necesidades básicas para programar
- Es de tipado fuerte esto significa que tendremos que declara cada valor con el tipo de datos correspondiente
- Esta orientado al ahorro de memoria  por que fue diseñado para tener una alta carga de trabajo lo que lo hace ideal para grandes entornos de producción
- Es compilado primero se crea un ejecutable para que el servidor lo ejecute
- No es orientado a objetos, no es necesario la creación de clases esto ayuda en la performance de la aplicación, la declaración de rutas se hace con funciones o métodos, todo dentro de una interface
- el compilador te advierte de variables no utilizadas o no declarada. esto mejora la legibilidad del código y el rendimiento del mismo
